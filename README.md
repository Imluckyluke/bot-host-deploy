# اجرای بات بدون داکر (روی خود سرور)

## این بسته چیست؟
۵ فایل برای انتقال بات + سرور OpenCode از کانتینر داکر به اجرای مستقیم روی هاست
(با systemd به‌جای حلقه entrypoint). نسخه‌ها دقیقاً همان‌هایی‌اند که الان در کانتینر اجرا می‌شوند.

| فایل | کاربرد |
|---|---|
| `install.sh` | نصب Node 22، کپی فایل‌ها از کانتینر، ساخت `.env`، نصب و استارت سرویس‌ها |
| `opencode-server.service` | یونیت systemd سرور OpenCode (پورت داخلی 49374) |
| `opencode-bot.service` | یونیت systemd بات تلگرام (ری‌استارت خودکار) |
| `.env.example` | نمونه متغیرها (اسکریپت خودش `.env` واقعی را از کانتینر می‌سازد) |

## مراحل (روی هاست، با root)
1. این ۵ فایل را در یک پوشه بریز، بعد:
   ```
   chmod +x install.sh
   ./install.sh [container-name]
   ```
   اسم کانتینر را نمی‌دانی؟ اول `docker ps` بزن و اسم را بده.
2. صبر کن تا `BOT ACTIVE ✅` را ببینی؛ بعد در تلگرام به بات پیام بده. جواب داد = موفق.
3. **فقط بعد از تأیید قدم ۲**، کانتینر قدیمی را حذف کن تا ~۱۵ گیگ آزاد شود:
   ```
   docker stop <name> && docker rm <name> && docker system prune -a
   ```

## نکته‌ها
- چیزی در تلگرام و سشن‌ها گم نمی‌شود: دیتا (`/opt/bot/data`) و توکن‌ها از کانتینر کپی می‌شوند.
- لاگ‌ها: `journalctl -u opencode-bot.service -f` و `journalctl -u opencode-server.service -f`
- ری‌استارت دستی: `systemctl restart opencode-bot.service`
- پورت 49374 فقط روی localhost باز است؛ بات خروجی به تلگرام وصل می‌شود، پورتی لازم نیست باز کنی.
